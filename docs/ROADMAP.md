# Revenue Command roadmap

The sequence is a direction, not a commitment to implement every item. Prioritize the shortest useful revenue execution loop.

## 1. Repository foundation — complete

Initialize the requested stack, strict tooling, docs, responsive shell, working navigation, and an honest placeholder Command page. Validate lint, type-check, build, and functional navigation.

## 2. First operator workflow — complete in this slice

Prospect CRUD, intelligence, score/classification, Command ranking, editable ICP Call Prep, Call Debrief, and recommended next action now work using browser-local persistence. No external database or CRM is required.

## 3. Opportunity execution

Connect prospect context to an offer, an economic hypothesis, stage, owner, and follow-up. Make confirmed evidence distinct from assumptions. Prioritize visible next actions and revenue movement over broad reporting.

## 4. Offers and messaging

Create reusable Playbooks grounded in Sekairos terminology. Help the operator prepare relevant outreach and record the outcome. External sending services or AI APIs require explicit instruction.

## 5. Operational readiness

Scope access control, storage, deployment, and observability before real sensitive data is used. Add integrations only after the operator workflow demonstrates a concrete need and the user authorizes them.

## Deferred

Multi-tenant SaaS, billing, a generic workflow engine, autonomous outreach, complex scoring, a data warehouse, and elaborate infrastructure are outside the foundation and should not be prebuilt.
